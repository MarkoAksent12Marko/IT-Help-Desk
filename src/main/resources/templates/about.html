PROJECT OVERVIEW

Why I Built This Project

I created this IT Help Desk application to gain practical experience designing and developing a full-stack system based on a real business process.

The application allows users to create accounts, securely sign in, submit IT support requests, and track their tickets. An administrator account can view requests submitted across the system and manage their status.

Building this project gave me hands-on experience connecting a Java backend to a database and web interface while implementing authentication, authorization, data management, and ticket management.

Technologies Used

Java Spring Boot Spring Security Spring Data JPA H2 Database Thymeleaf HTML CSS

Key Features

User Authentication

Users can register and securely sign in to their own accounts.

Ticket Management

Users can submit IT support requests and track their status.

Admin Dashboard

Administrators can view tickets from all users and manage their status.

Database Integration

User accounts and ticket information are managed through a relational database.
