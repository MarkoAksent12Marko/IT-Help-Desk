# IT-Help-Desk

Full-stack IT help desk application built with Java and Spring Boot for submitting, tracking, and managing support tickets.

## 🌐 Live Demo

[Launch IT Help Desk](https://it-help-desk-production-4869.up.railway.app)

## Features

- User registration and authentication
- Secure password encryption
- Submit and track support tickets
- Ticket priority and status management
- Separate administrator dashboard
- Admin ticket status updates
- Persistent database storage

## Technologies

- Java 21
- Spring Boot
- Spring Security
- Spring Data JPA
- Thymeleaf
- HTML & CSS
- H2 Database
- Maven
- Git & GitHub
- Railway
